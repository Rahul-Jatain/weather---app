# Weather App

A simple Python Weather App that uses the OpenWeatherMap API to get current weather information.

## Features

- Search weather by city name
- Temperature
- Feels like temperature
- Weather condition
- Humidity
- Wind speed
- Handles invalid city names
- Handles internet connection problems

## Requirements

- Python 3
- requests library
- OpenWeatherMap API key

## Installation

Install the requests library:

pip install requests

## API Key

Open `weather_app.py` and replace:

API_KEY = "YOUR_API_KEY_HERE"

with your own OpenWeatherMap API key.

## How to Run

Run:

python weather_app.py

Then enter a city name to get its weather information.

## Note

You need your own OpenWeatherMap API key to use this application.
